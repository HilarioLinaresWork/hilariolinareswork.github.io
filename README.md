# Hilario Linares — Job Portfolio

A static, responsive work portfolio hosted for free on GitHub Pages.

## Upload / publish

1. Open the `HilarioLinaresWork/hilariolinareswork.github.io` repository.
2. Choose **Add file → Upload files**.
3. Upload the files **inside this folder**, including the `assets` directory. `index.html` must be in the repository's root, not a nested folder.
4. Commit the files to `main`.
5. The site should update at `https://hilariolinareswork.github.io/` after deployment.

## Editing

- `index.html`: all displayed text, skills, job experience, and gallery image references.
- `styles.css`: layout, colors, fonts, responsive design.
- `script.js`: photo-gallery category filters and mobile navigation.
- `assets/`: portfolio sample images. Replace these with your own photos later, using the same filenames or updating `src` values in `index.html`.

## Important

The separate **sample gallery** contains illustrative placeholders, clearly labeled as such. The Shed and Bathroom project sections use actual photographs supplied for this portfolio. Do not represent stock photos as evidence of work. Avoid posting past employers' proprietary drawings, customer information or government-project details. The contact section intentionally does not include an unconfirmed email address or phone number.
